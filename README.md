Subspace.money Product Teardown
Product Intern Assignment – 2026

Company Snapshot
ARR (FY25): 36.5 Cr  

Play Store Rating: 3.6/5  

The 5 Product Pillars: Key Fixes
01. UX (Trust Layer): Current credential sharing relies on unsecured group chats, leading to trust failures and churn.  

Ship Instead: Build a Credential Vault with automated delivery and a 48-hour payment escrow.  

02. Features (Auto-Detection): Advertised "auto-detection" actually requires manual data entry, frustrating budget-conscious users.  

Ship Instead: Implement true automation via SMS parsing, UPI transaction pulls, and "Smart Remind" push notifications.  

03. GTM & ICPs: The homepage confuses users by mixing digital subscriptions with city-specific gadget rentals.  

Ship Instead: Separate the Go-To-Market motions, leading the homepage entirely with the core subscription business.  

04. Competitor Analysis: Grey-market sharing risks immediate shutdown from upcoming Netflix/Prime password crackdowns.  

Ship Instead: Pivot to coordinating legally sanctioned, multi-user plans (e.g., YouTube Family, Spotify Family) as a distribution partner.  

05. Collaborations: Despite claiming to be a marketplace for local providers, there is no way for businesses to onboard.  

Ship Instead: Launch a self-serve B2B "Provider Portal" to easily onboard local gyms, tutors, and meal kits.  

SWOT Summary
Strengths: 36.5Cr ARR (bootstrapped/profitable), unique Negotiate API.  

Weaknesses: Fragmented product identity, trust deficit (3.6 stars), manual tracking.  

Opportunities: 20%+ YOY OTT growth, 120M+ student market, B2B local subscriptions.  

Threats: Imminent OTT account-sharing crackdowns, super-app competitors (CRED/PhonePe).
